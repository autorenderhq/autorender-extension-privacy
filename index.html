Privacy Policy – AutoRender Demo Chrome Extension Last updated: 2026-01-15 The AutoRender Demo Chrome Extension is designed solely to demonstrate image optimization by rewriting image URLs on user-selected webpages to AutoRender CDN URLs. 1. Data Collection This extension does not collect, store, sell, or share: Personally identifiable information Browsing history Page text or form inputs Cookies or authentication data 2. Data Usage The extension operates locally in the user’s browser. Its only function is to detect image resources on a webpage and replace their URLs with AutoRender CDN URLs for performance demonstration purposes. 3. Network Requests When enabled, the extension may: Load optimized images from AutoRender CDN domains Fetch configuration data such as workspace or preset identifiers No personal user data is transmitted as part of these requests. 4. Local Storage The extension may store non-personal configuration data locally using Chrome storage, including: Workspace ID Demo token Enabled/disabled site preferences This data never leaves the user’s browser except when required to generate optimized image URLs. 5. Third-Party Sharing The extension does not share user data with third parties. 6. User Control The extension runs only when explicitly enabled by the user and only on sites the user chooses. Users can disable or remove the extension at any time. 7. Changes This privacy policy may be updated to reflect changes in extension functionality. Updates will be reflected on this page. 8. Contact For questions about this privacy policy, contact: support@autorender.io
