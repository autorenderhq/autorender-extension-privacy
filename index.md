# Privacy Policy – AutoRender Demo Chrome Extension

**Last updated:** 2026-01-15

The **AutoRender Demo Chrome Extension** is designed solely to demonstrate real-time image optimization by rewriting image URLs on user-selected webpages to AutoRender CDN URLs. This allows users to preview faster-loading, optimized images without modifying the website’s source code.

---

## 1. Data Collection

The AutoRender Demo Chrome Extension **does not collect, store, sell, or share** any of the following:

- Personally identifiable information
- Browsing history
- Page text or form inputs
- Cookies or authentication data
- User credentials

---

## 2. How the Extension Works

When enabled by the user, the extension:
- Detects image resources (`<img>` tags and CSS background images) on the active webpage
- Rewrites those image URLs to AutoRender CDN URLs for optimization and performance demonstration
- Operates only on sites explicitly enabled by the user

All processing occurs locally within the browser.

---

## 3. Network Requests

The extension may make network requests to:
- Load optimized images from AutoRender CDN domains
- Fetch non-personal configuration data such as workspace identifiers or preset information

No personal user data or webpage content is transmitted as part of these requests.

---

## 4. Local Storage

The extension uses Chrome’s local storage to save non-personal configuration data, including:
- AutoRender workspace ID
- Demo or access token
- Enabled or disabled site preferences
- Extension on/off state

This data remains local to the user’s browser and is never shared with third parties.

---

## 5. Third-Party Data Sharing

The AutoRender Demo Chrome Extension **does not share user data** with any third parties.

---

## 6. User Control

Users have full control over the extension:
- The extension runs only when explicitly enabled
- Users can disable the extension for specific sites or entirely
- The extension can be removed at any time through Chrome’s extension manager

---

## 7. Security

The extension is designed with a single, limited purpose and does not access sensitive browser data or privileged APIs beyond what is required to demonstrate image optimization.

---

## 8. Changes to This Policy

This privacy policy may be updated if the extension’s functionality changes. Any updates will be reflected on this page with a revised “Last updated” date.
